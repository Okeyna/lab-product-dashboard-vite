# Dynamic Product Dashboard Lab: Execution Guide

This guide provides step-by-step instructions to execute the **Dynamic Product Dashboard** lab. Follow these steps to set up your environment, build the components, run the tests, and submit your solution.

---

## 📋 Prerequisites
Before starting, ensure you have the following installed:
- **Node.js** (v14 or higher)
- **npm** or **yarn**
- **Git**
- A code editor (e.g., VS Code)

---

## 🚀 Step 1: Project Setup

### 1.1 Initialize the Project
Open your terminal and run the following commands to clone and run the application

```bash
git clone <repo>
npm install
